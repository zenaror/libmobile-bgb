# Memória do projeto na OMM

Este projeto integra o libmobile ao emulador BGB. A OMM guarda as decisões e o estado durável; o código e os documentos deste repositório continuam sendo as fontes para confirmar como a implementação funciona.

## Ao começar

1. Leia `AGENTS.md` e consulte a OMM no escopo `libmobile-bgb`.
2. Confira branch, commit e alterações locais, inclusive o submódulo `subprojects/libmobile`.
3. Use a skill compartilhada `reon-libmobile-expert` para questões de domínio REON/libmobile, conferindo as fontes originais antes de concluir.
4. Registre fatos com origem e mantenha separado o que foi observado, inferido ou ainda não foi confirmado.

## Integração

- Escopo OMM deste projeto: `libmobile-bgb`.
- Biblioteca integrada: `subprojects/libmobile` (projeto relacionado, com estado e histórico próprios).
- O OMM não substitui o histórico Git nem transforma alterações locais em fatos confirmados.
- Adicione dados compartilhados sobre REON/libmobile ao escopo `global` somente quando forem úteis a outros projetos; mantenha detalhes específicos do emulador BGB neste escopo.
